# 矢量描边与填充

一个纯标准库的矢量图形渲染器：解析路径文件，按曲率自适应细分贝塞尔，
用精确覆盖率抗锯齿地填充与描边，输出确定性 PNG。

## 运行

```
python -m vector.cli data/shape.txt --width 320 --height 320 --out vector.png
python -m pytest tests -q
```

`shape.txt` 是一条由两段三次贝塞尔组成的闭合叶片，带 6 像素描边和填充色。

## 实现要点

### 曲线细分

`flatten_curve` 默认用 de Casteljau 二分做自适应细分。判据是严格上界
`max(d(p1, 弦), d(p2, 弦))`：三次贝塞尔曲线是控制点的凸组合，而「点到线段
的距离」是凸函数，所以曲线到弦的距离一定不超过两个控制点到弦距离的较大者。
曲率大的地方控制点离弦远，自然被拆得更密；平缓的长曲线不会被过度细分。
默认容差 0.25 像素，实测最大偏差 < 0.2 像素。传 `segments=` 时退化为固定
段数均分（保留旧接口）。

### 填充

`fill_polygon` 按奇偶规则填充：每行取 8 条子扫描线，求扫描线与多边形边的
全部交点、两两配对成内部区间；区间与像素格的横向重叠给出该子行的精确覆盖率，
再对子行取平均。自交区域因此被交替判为内外，覆盖率数值与几何面积一致。

### 描边

`stroke_polyline` 把每条线段外扩 `width/2` 形成胶囊（圆角），对胶囊求并集后
用与填充相同的「区间—覆盖率」扫描线累加。并集的两个性质正好对应两条要求：

- 相邻线段的胶囊必然重叠，拐角不会断开；
- 覆盖区域永远不超过胶囊，不会出现尖刺。

闭合路径的首尾是同一点，首尾接缝与普通顶点走完全相同的代码路径，因此平滑无接缝。
线宽 1 到 20 像素都成立，覆盖面积与 `width × 长度 + 两端半圆` 的解析值误差 < 1%。

### 抗锯齿

两种图元都在 x 方向解析积分、y 方向取子扫描线，覆盖率是几何量而不是
「距离减半宽」的近似。斜边和曲线的边缘因此得到与像素内真实面积一致的灰度过渡。

### PNG

`save_png` 手工编码 24 位 RGB PNG：不写入时间戳等元数据，固定 filter 类型与
压缩级别，所以同一份输入连续运行两次的输出逐字节相同。

## 实测数据

`python -m vector.cli data/shape.txt --width 320 --height 320 --out vector.png`
（320×320，共 102400 像素）：

| 类别 | 像素数 | 判定方式 |
| --- | ---: | --- |
| 描边像素 | 2684 | 与描边色 (30, 30, 60) 完全相等的像素 |
| 填充像素 | 21196 | 与填充色 (235, 200, 90) 完全相等的像素 |
| 边缘过渡像素 | 1339 | 既非纯背景、也非纯描边/填充色的抗锯齿像素 |
| 背景像素 | 77181 | 纯白 (255, 255, 255) |

四类合计 102400，覆盖全部像素。两次运行 `vector.png` 的 SHA-256 相同。

## 测试覆盖

`python -m pytest tests -q`（23 项）覆盖：

- 细分偏差上界：多组长/急弯/自交曲线，曲线到折线与折线到曲线的双向偏差均 < 1 像素；
  细分密度随曲率和长度增加；`tolerance` 参数严格生效。
- 线宽生效：1..20 像素覆盖像素数严格单调增加；覆盖面积与解析值误差 < 1%。
- 闭合接缝连通：闭合路径起点周围整圈有描边覆盖；普通顶点两侧扫描线无洞；
  拐角全角度有覆盖且无尖刺（覆盖不超出胶囊范围）。
- 填充非空：闭合叶片填充像素 > 5000 且内部为填充色；自交区域按奇偶规则交替；
  填充与描边交界两侧均无白色缝隙。
- 抗锯齿：斜边存在灰度过渡；覆盖率与几何面积一致（半平面 0.5 覆盖、
  子像素平移时线性变化到 3/255 以内）。
- 两次输出一致：同输入两次渲染得到完全相同的 PNG 字节。
